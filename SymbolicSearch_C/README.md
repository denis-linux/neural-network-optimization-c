# SymbolicSearch_C — семантический поиск без нейросети

Эксперимент на C11, не изменяет TinyTalk_Reason. Система использует существующие TSV-примеры намерений как поисковый индекс: нормализация UTF-8, префиксы русских слов, явно заданные смысловые группы и ранжирование по совпадениям. Никаких нейросетевых весов или обучения.

## Запуск

```sh
cc -std=c11 -O2 -Wall -Wextra SymbolicSearch_C/search.c -o /tmp/symbolic_search
/tmp/symbolic_search TinyTalk_Reason/data.txt "сколько калорий осталось"
/tmp/symbolic_search TinyTalk_Reason/data.txt "поставь таймер"
bash SymbolicSearch_C/test.sh
```

Вывод: намерение, оценка совпадения и ближайший пример. Если совпадений недостаточно, `UNCERTAIN`.

## Метод и ограничения

Поисковик читает `текст<TAB>метка` и сравнивает запрос с каждым примером. Совпадение понятий (например, «остаток» и «доступно») имеет больший вес, чем совпадение текстовых префиксов. Для каждого намерения берётся максимальная оценка среди его примеров. Никакой вероятностной интерпретации score нет.

Это прототип распознавания намерений, **не универсальный семантический анализ**. Роли, отрицания и сложные перефразировки могут распознаваться неверно. Тесты — smoke-тесты, а не научная оценка качества. Модуль пока не интегрирован с `respond()`: прежде нужно сравнить его с MLP на независимом test и настроить порог отказа на validation.
