# Distributed AI C v0.2

Исследовательский прототип на C11/Linux/POSIX. MLP 2–16–1 (65 параметров), tanh, sigmoid, binary cross entropy. Синтетическая классификация XOR по знакам координат. Не языковая модель.

## Запуск
```bash
cd Distributed-AI-C
chmod +x *.sh
./build.sh
./test.sh
./experiment_slow.sh
```
На сервере: `./start_server.sh 9000 2000 4096 127.0.0.1`. На каждом клиенте: `./start_worker.sh 127.0.0.1 9000 0`. Последний аргумент — искусственная задержка (мс). Для отдельных компьютеров используйте частный адрес координатора и изолированную доверенную сеть. После обучения остановите сервер Ctrl+C. Веса сохраняются в model.txt.

## Алгоритм
Координатор передаёт версию, снимок весов, номер задания и размер пакета. Клиенты независимо вычисляют усреднённые градиенты. Координатор принимает конечные градиенты с модулем не более 4 и возрастом не более 8 обновлений, применяя шаг 0.8/(1+age). Пакеты генерируются детерминированно. Тестовая выборка — 10000 примеров.

## Изменения v0.2
- Ошибка чтения команды остановки больше не трактуется как успешное завершение клиента.
- Лимит 64 активных соединений.
- Тайм-ауты чтения и записи клиента 10 с, сервера 5 с.
- Атомарная замена model.txt посредством rename и сообщение об ошибке сохранения.
- Проверка параметров формата double и обработка ошибок accept.

## Ограничения
Нет TLS, аутентификации, защиты от отравления модели или ограничения CPU. Не открывать порт в интернет. Публикация исходного кода не означает разрешение на подключение к работающим узлам. Вся модель хранится на каждом клиенте. Адаптивный размер пакета и распределение самой модели не реализованы. Тесты выполнены на одной машине через loopback, не на физических смартфонах. Сервер остаётся запущенным после обучения. Время включает ожидание подключения; сравнение при одинаковом количестве обновлений, а не при одинаковой точности. См. results/validation.txt.
