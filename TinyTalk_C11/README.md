# TinyTalk — небольшая нейросеть на C11, обучение с нуля

Никаких скачанных моделей, чужих весов, Python, PyTorch и доступа к интернету во время обучения. В архиве исходники, данные и Bash-скрипты. Веса создаются на вашем компьютере из случайных чисел.

## Что именно умеет эта модель

Она получает реплику и **выбирает один целый ответ из ответов обучающего файла**. Например: «привет» → «Привет, как дела?». Это настоящая обучаемая нейросеть-классификатор ответов: два слоя, tanh, softmax, перекрёстная энтропия, обратное распространение и SGD. Это НЕ авторегрессионная языковая модель: она не сочиняет новые предложения по словам и не поддерживает память диалога. Такой вариант позволяет видеть обычное обучение на маленьком компьютере без огромных корпусов.

При запросе программа не ищет точное совпадение строки в data.txt: файл данных вообще не нужен для использования сохранённой модели. Текст ответа берётся из списка меток сохранённой модели после нейросетевого предсказания. Новые формулировки могут распознаваться, но ошибки возможны.

## Быстрый запуск

Распакуйте архив и откройте терминал в папке TinyTalk_C11:

```bash
bash start_learning.sh
bash start_E.sh
bash chat.sh
```

Первая команда компилирует код и обучает v0001 с нуля. Вторая показывает PASS/FAIL с ожидаемыми и фактическими ответами. Третья запускает диалог; выход — /quit.

Требуются Bash, GCC или Clang и стандартная математическая библиотека. На Linux обычно достаточно установленного C toolchain. На macOS Intel код предназначен для сборки Clang; если компилятора нет, выполните `xcode-select --install`. Автоматической установки ПО в скриптах нет. Реально проверено на Linux, macOS в этом опыте не запускалась.

`start_eval.sh` — дополнительное имя для того же скрипта проверки. Запуск через `bash` не требует chmod. Никаких библиотек машинного обучения загружать не нужно.

## Данные

data.txt содержит 648 учебных пар и 40 разных ответов: 324 исходные формулировки и ещё 324 варианта с добавлением «слушай». Это небольшой авторский демонстрационный корпус, а не независимый большой датасет. Темы: приветствия, знакомство, настроение, благодарность, прощание, еда, отдых, прогулки, работа, учёба, музыка, книги, кино, поздравления, просьбы о помощи и другие бытовые реплики.

Одна строка — два поля, разделённые настоящим символом TAB:

```text
привет	Привет, как дела?
как дела	Всё хорошо, спасибо! А у тебя?
```

В редакторе используйте табуляцию между репликой и ответом, не пробелы и не буквальные символы `\t`. Файл — UTF-8. Строки, начинающиеся с #, являются комментариями. Один и тот же ответ для разных формулировок пишите совершенно одинаково: разные знаки препинания образуют разные классы. Не назначайте одной и той же реплике разные ответы: скрипт обнаруживает такое противоречие.

Можно дописывать пары прямо в data.txt. При продолжении обучения скрипт объединяет актуальный data.txt с предыдущей обучающей выборкой, удаляет точные дубли и сохраняет старые примеры. Можно также передать отдельный файл новых данных. Лимиты: 256 разных ответов, 20000 пар, строка короче 8191 байта, на входе анализируются первые 1024 Unicode-кодовые точки. Модель ориентирована на русский/английский текст и цифры.

## Дообучение и версии

После первого обучения выполните:

```bash
EPOCHS=60 bash start_learning.sh --resume extra_data.txt
bash compare_versions.sh 'какой твой любимый цвет'
EPOCHS=40 bash start_learning.sh --resume
EPOCHS=40 bash start_learning.sh --resume
bash start_E.sh v0004
```

Получатся v0001, v0002, v0003, v0004. extra_data.txt добавляет восемь примеров нового ответа «Мой любимый цвет — синий.». Проверить его:

```bash
EXTRA_TESTS=tests_extra.tsv bash start_E.sh v0002
```

Обычный повторный вызов start_learning.sh тоже продолжает последнюю модель. Флаг --fresh начинает новую независимую модель со случайных весов, но сохраняет старые версии. При изменении уже существующего ответа проще исправить data.txt и использовать --fresh: накопленная выборка предыдущей версии намеренно сохраняется при resume.

Количество дополнительных эпох задаётся EPOCHS, по умолчанию 160. Больше эпох не означает лучшее понимание: маленький корпус можно переучить. При resume продолжаются сохранённые веса, счётчик эпох и генератор случайных чисел. Оптимизатор — обычный SGD без momentum, отдельного состояния моментов нет. Порядок примеров заново перемешивается, поэтому это продолжение обучения, но не обещание побитового совпадения с одним непрерывным запуском на суммарное число эпох.

Каждая версия хранится отдельно:

```text
models/v0001/model.bin
models/v0001/training.tsv
models/v0001/train.log
models/v0001/parent.txt
models/v0002/...
models/latest.txt
```

training.tsv — точная выборка этой версии, parent.txt — её предок. После ошибки обучения latest.txt не переключается на неготовую модель. Одновременное обучение защищено директорией models/.training_lock. После принудительного завершения процесса её можно удалить, предварительно убедившись, что обучение больше не идёт.

## Что находится внутри нейросети

1. Нормализация регистра, ё→е; выделение слов и символьных фрагментов длиной 2–4.
2. Преобразование этих признаков в 2048 фиксированных хеш-корзин, нормирование длины вектора. Эта часть не обучается.
3. Обучаемый скрытый слой из 48 нейронов с tanh.
4. Обучаемый выходной слой: по одному выходу на каждый ответ.
5. Softmax и выбор максимума.

Во время обучения ошибка предсказания обновляет веса обоих слоёв. При новом ответе добавляется новый выход, старые веса сохраняются. Хеш-признаки позволяют обрабатывать новые слова без пересборки словаря. Но коллизии, потеря части порядка слов и короткий контекст ограничивают качество.

Размер модели с 40 ответами — около 0.4 MB. model.bin содержит ответы, веса, смещения, счётчик эпох и состояние RNG. Бинарный формат рассчитан на совместимые платформы с 32-битными int/float и одинаковым порядком байтов, например типичные Linux x86_64 и Intel Mac; универсальная переносимость между всеми архитектурами не обещается.

## Проверки и их смысл

В start_E.sh прямо записаны шесть пар «реплика / ожидаемый ответ». Дополнительно используются:

- tests_seen.tsv: 40 знакомых реплик, по одной на ответ.
- tests_unseen.tsv: 24 другие формулировки, не использовавшиеся для обучения; это ручной маленький набор, не научный бенчмарк.
- tests_extra.tsv: новый ответ из extra_data.txt, проверяется по EXTRA_TESTS.

Код возврата start_E.sh — 1, если хотя бы одна проверка не прошла. Это результат проверки, а не обязательно поломка программы. Отчёты записываются в reports. Можно сравнить любую версию отдельно или вызвать `bash compare_versions.sh 'ваша фраза'`.

Результат проверенного Linux-запуска: базовая версия после 160 эпох — 6/6, 40/40 и 23/24 соответственно. После добавления нового ответа и двух дальнейших продолжений знакомые ответы сохранились, новый ответ выдавался в v2/v3/v4. Единственная ошибка независимого набора — «можешь работать офлайн». Она оставлена в тестах, а не скрыта подбором данных.

В папке verified_results лежат журналы нашего опыта. Обученных файлов model.bin в архиве нет: первая модель действительно будет создана с нуля у вас.

Дополнительная проверка всего цикла в изолированной временной папке:

```bash
bash test_workflow.sh
```

Она обучает четыре версии, проверяет старые и новые ответы, неизменность первой модели и запуск из пути с пробелами. Проверенные сценарии также запускались с AddressSanitizer/UBSan. LeakSanitizer пришлось отключить из-за ограничения среды ptrace, поэтому отдельная проверка утечек не заявляется.

## Ограничения

Модель всегда выбирает один из известных ответов; надёжного обнаружения незнакомой темы здесь нет. Даже высокий softmax-score не гарантирует правильность. Пример «Я не знаю ответа» является обычным обученным ответом, а не универсальным фильтром неизвестных запросов. Модель не знает реальную погоду, время, личные данные и не выполняет команды ОС. Реплики в данных — демонстрационные ответы, не подтверждение чувств или предпочтений программы.

Архив предназначен для изучения обучения небольшой нейросети. Он не заменяет LLM и не заявляется как научная новизна.
